## 🚀 About Church Hub Desktop

Church Hub Desktop is a secure administrative desktop platform designed for churches and faith-based organizations to manage:

- 👥 Members
- 🏛 Roles & permissions
- 🙏 Ministries & groups
- 💳 Contributions (tithe, offerings, harvest, dues)
- 📊 Financial tracking & reporting
- 🏢 Multi-tenant church environments

The landing page reflects an **enterprise-grade**, subscription-based product.

## 💻 OS Detection Logic

The Hero component detects the user's operating system and conditionally renders:

- "Subscribe & Download for Windows"
- "Subscribe & Download for macOS"

Detection uses:

```js
window.navigator.platform
```
